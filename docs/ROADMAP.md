# Roadmap

## Current Focus

| Status | Area | Goal | Notes |
|---|---|---|---|
| In Progress | Multi-channel / Multi-module support | Evolve the project from single-channel EMG to a modular, expandable architecture. | Tracked in [Issue #1](https://github.com/arn-c0de/AD8232-EMG/issues/1). |

## Planned Expansion

| Status | Area | Goal | Notes |
|---|---|---|---|
| Planned | Firmware | Channel-aware acquisition and transport layer | Start with dual-channel support, then scale further. |
| Planned | API | Structured multi-channel data model | Add per-channel metadata and timestamps. |
| Planned | GUI | Multi-channel visualization and controls | Add labeling, grouping, and per-channel thresholds. |
| Planned | Signal Processing | Cross-channel analysis and gesture detection | Begin with simple multi-muscle features before advanced classifiers. |
| Planned | Modularity | Expandable sensor/module architecture | Keep the design open for additional sensor types later. |

## Immediate Next Step

| Priority | Deliverable | Reason |
|---|---|---|
| Next | Dual-channel forearm EMG support | Smallest useful step beyond the current single-channel implementation. |
